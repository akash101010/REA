# REA — Reverse Engineer Anything

This is an unofficial mirror of the open-source REA project. The upstream repository and its maintainers remain the source of truth.

- Official source and releases: [morluto/rea](https://github.com/morluto/rea)
- Official website: [rea.tools](https://rea.tools/)
- Complete project source archive: [rea-main.zip](./rea-main.zip), including the original code, documentation, website, workflows, and license.

## Website

GitHub Actions builds the existing static website from the source archive and publishes it through GitHub Pages. After the first successful deployment, it will be available at [https://akash101010.github.io/REA/](https://akash101010.github.io/REA/).

The site serves documentation, guides, and examples. REA's analysis tools run locally after installation; GitHub Pages does not run the REA CLI or MCP server.

## Credentials

No provider API key is included. Configure provider credentials locally and keep them out of source files and Git history.
